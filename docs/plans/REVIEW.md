## Summary

17 findings are open: medium 5, low 7, judgement 5. Completed findings are removed from this file; the commit that fixed each one is in the git history.

The 2026-11-18 pass removed 27 rows: 24 fixed (R-72, R-74, R-75, R-76, R-77, R-83, R-87, R-90, R-91, R-100, R-103, R-105, R-106, R-108, R-112, R-113, R-114, R-115, R-116, R-118, R-121, R-125, R-128 and R-130), and 3 that no longer apply in the form written (R-85, R-92, R-98). The fixes are uncommitted. `cargo check --workspace --all-targets`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --check` and `cargo test --workspace` all pass. The fixes marked unmeasured have no before-and-after numbers.

Four rows need a design decision from the owner: R-86 (one decode per file), R-109 (cap the pairs per image?), R-117 (cancel the Yandex pace) and R-124 (the remaining public API of the catalog). R-126 (a writer thread for commits) also needs one. Each row's next step says what it would change. R-66 and R-84 stay open until they are measured.
