Photo Gallery

A desktop photo gallery for very large libraries, built around near-duplicate detection: many crops and edits of the same picture, and the same pin saved at different sizes.

Non-destructive by design: nothing is deleted automatically.

Source on GitHub Build it

What it is made of

  • Rust core

    Scanning, the SQLite catalog, decoding and thumbnails, and duplicate detection.

  • Qt 6.12 and QML

    The window is QML, bridged to Rust through cxx-qt.

  • Windows only, for now

    The app targets Windows; the workspace also builds and tests on Linux in CI.

Build

The compiler is pinned in rust-toolchain.toml, so rustup installs the right one on first use. The Qt kit, the FFmpeg build and ExifTool are described in crates/README.md. This machine's paths go in .env (copy .env.example): just doctor says what is missing, and just setup fetches the pinned FFmpeg. The commands need just:

just            # lists the commands
just lint       # formatting, clippy, dependency checks, Python and Markdown, QML
just test       # the Rust tests
just qmltest    # the QML tests
just deploy     # the release build, with Qt's DLLs and QML modules next to gallery.exe
