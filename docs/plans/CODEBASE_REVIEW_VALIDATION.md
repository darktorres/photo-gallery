## Method

- Each validation batch was read in full. Every cited site was checked against the tree with grep, sed or a build check, and every named path, symbol, count and quoted text was looked up. No spot-checks.
- CONFIRMED: the live code or file supports the claim. PARTIAL: part of the claim holds, or a premise was not verified. REFUTED: the cited text resolves, or the premise is wrong.
- Archived third-party HTML was judged as source text.

### Fix first

Severity labels understate several of these. Items marked "checked" were confirmed a second time.

1. **Archived page bytes** (new, checked by hashing). Captures 27, 40, 51, 58 and 65 match `MANIFEST.tsv` only
   in this working tree; their committed copies differ by removed carriage returns, and `git status` shows
   clean. Capture 36 matches in neither, and can be restored by adding the carriage returns back. Copy the five
   files somewhere durable, then apply `captures.byte-pins`.
2. **Write-back can delete the only whole copy** (RV-0770, RV-0879, RV-0891; checked by reading, not
   reproduced). The temp record is not durably synced. If power loss drops it during the in-place copy, the next
   run removes the temp as a leftover (`crates/writeback/src/lib.rs:576`).
3. **A failed catalog rebuild can leave an empty library** (RV-0760; checked by reading). The old file is moved
   aside before the new one takes its name, and opening a missing path creates a database. Fix this before any
   `baseline.sql` edit, because such an edit rebuilds existing catalogs.
4. **Read errors become results** (RV-0872, RV-0873). An unreadable file is recorded as a failed analysis, and a
   mid-stream video read error yields a wrong frame as success.
5. **Lint gates skip production code** (RV-0956; the `boundaries.py` mechanism checked by reading). Both test
   cuts hide code from the checks. Fix before large refactors.
6. **The eval cannot find its test set** (RV-1162; checked by reading). Commit `94c4dec0` changed the default
   `DATA_ROOT` to `datasets`, while `ground_truth` still expects paths that start at the test set's folder.
7. **The encoder harness is broken** (new; checked by reading). `eval/jpeg-encoder/build.ps1` looks for the
   libjpeg headers outside `src/`, and test 5 expects 65501 to be rejected although `EGPU_MAX_DIM` is now 65535.
   See the Eval notes under "Shared fixes".
8. **Lane races and hangs** (RV-0828, RV-0821). A hold or stop can be cleared as a round starts, and dropping a
   stuck service blocks forever.

### Decisions for the owner

Each has a recommendation; the full reasons are in the findings' "Needs" cells.

6. **Real Size setting** (RV-0559, RV-1164). Recommend: keep it as a per-device preference, off by default, and

7. **How docs cite code** (RV-0386, RV-1431, RV-1432). Recommend: declare each doc live or record. Live docs

8. **Misspelled dataset folder** (RV-0664). Recommend: rename it to `similar_but_not_dups`, which needs you to

9. **Encoder thresholds** (RV-1278). Recommend: claim only what history shows (the one-sided band was set after

10. **Linux file systems** (RV-0870). Recommend: an allow list of known local ones, with `fuseblk` only for

11. **Unreadable preferences file** (RV-0746). Recommend: never move or overwrite it, run on defaults with

12. **A typed "1,234"** (RV-0779). Recommend: refuse it when a comma is followed by exactly three digits after a

13. **Temporary CI diagnostics** (RV-0019, RV-1325). Recommend: remove both and their `--timings` flags.
